01 / EL PROYECTO

Una idea de la aviación, llevada al aula.

Un banco de pruebas permite observar el comportamiento de un generador fuera de la aeronave y bajo condiciones controladas. El BPGA reproduce ese principio a escala con una finalidad educativa.

El proyecto reúne máquinas eléctricas, instrumentación, sistemas embebidos, comunicaciones industriales y software. No es un equipo aeronáutico certificado ni está habilitado para validar componentes aeronáuticos.

02 / CÓMO FUNCIONA

De una señal a una pantalla.

El recorrido actual empieza con datos simulados y termina en una interfaz local.

  1. 01

    Generación

    La EDU-CIAA genera variables mediante el Modo Simulador.

  2. 02

    Organización

    FreeRTOS organiza las tareas de la plataforma embebida.

  3. 03

    Comunicación

    Los valores se publican mediante Modbus RTU sobre RS-485.

  4. 04

    Consulta

    La Raspberry Pi consulta los registros disponibles.

  5. 05

    API local

    Una API HTTP local expone el estado del sistema.

  6. 06

    Supervisión

    La interfaz muestra monitorización, diagnóstico, arquitectura y resultados.

03 / DEMOSTRACIÓN ACTUAL

La plataforma digital en primer plano.

El Modo Simulador es la base de la muestra: sus variables recorren la cadena digital completa.

La posible adquisición física de RPM mediante giro manual está sujeta a validación. La tensión y la corriente no se presentan como mediciones físicas actuales.

ALCANCE DE LA MUESTRA

Etapa de potencia desenergizada

  • El motor no se conecta a 220 V.
  • El generador y las cargas no funcionan energizados.
  • El PLC todavía no interviene en la operación.

06 / ESTADO DEL DESARROLLO

Lo que funciona y lo que sigue.

Una plataforma educativa que avanza por etapas.

Implementado y validado

Plataforma digital

  • Firmware EDU-CIAA con FreeRTOS.
  • Modo Simulador.
  • Modbus RTU sobre RS-485.
  • Supervisor Raspberry Pi y API HTTP local.
  • Interfaz en modo quiosco.
  • Detección de datos congelados y pérdida de comunicación, con recuperación automática.
  • Prueba integral de treinta minutos.
En integración o validación

GPS y entradas físicas

  • GPS L86 conectado a USART3; recepción UART y sentencias RMC validadas.
  • Sincronización del RTC pendiente de una RMC válida.
  • Posible adquisición física de RPM, sujeta a validación.

No se utiliza 1PPS y el GPS aún no forma parte del mapa Modbus.

Evolución prevista

Hacia nuevas etapas

  • Sensores reales de tensión y corriente.
  • Integración completa del sensor de RPM.
  • Regulador de corriente de excitación.
  • Banco de cargas, PLC y protecciones.
  • Alimentación segura del conjunto motor-generador.
  • Validación de la etapa de potencia.

07 / EVOLUCIÓN PREVISTA

Un regulador por desarrollar.

En un generador de corriente continua con excitación independiente, la tensión puede regularse actuando sobre la corriente de campo. El BPGA contempló representar esa función.

El regulador fue estudiado conceptualmente, pero no fue construido ni validado. Actualmente no existe un lazo cerrado operativo.
